# Тестирование и отладка в превью Eden

Касается прогона кода в запущенной игре: вручную через debug console или агентом через
MCP (например `execute_sqf` из sqf-mcp).

## Перезапуск миссии

Перезапуск превью — `endMission "END1";`: миссия завершается, игра возвращается в Eden.
Что мешает:

- **Дебрифинг.** Без `debriefing = 0;` в description.ext после `endMission` превью
  останавливается на экране «Задание выполнено» (IDD 50). Кнопка «Далее» нажимается из
  кода: `ctrlActivate ((findDisplay 50) displayCtrl 1)` — следующим вызовом, после того
  как экран появился. Навигация по меню и редактору — [game-navigation.md](game-navigation.md).
- **Экран смерти (IDD 58).** Если игрок мёртв, этот экран блокирует `endMission`.
  Сначала закрой его или переключись на живого юнита, потом перезапускай:
  ```sqf
  if (!isNull findDisplay 58) then { (findDisplay 58) closeDisplay 2; };
  endMission "END1";
  ```

## Правки функций

Функции из CfgFunctions компилируются через `compileFinal`: правка `functions\*.sqf`
не подхватывается в уже запущенной миссии, нужен перезапуск. Код, переданный напрямую
(debug console, `execute_sqf`), выполняется сразу.

## Тесты с противником

Заспавненные враги быстро убивают игрока, после чего мешает экран смерти. Перед тестом
сделай игрока неуязвимым и невидимым для AI:

```sqf
player allowDamage false;
player setCaptive true;
```
